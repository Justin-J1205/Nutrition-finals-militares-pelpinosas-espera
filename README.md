NutriCare EHR - Tele-nutrition MVP

Project Overview

This is the final MVP for our Tele-nutrition & Digital Health Platform. It's a full-stack web application designed to connect dietitians and patients. It handles everything from patient meal tracking and automated clinical safety alerts to standardized medical charting and encrypted WebRTC video consultations.

Tech Stack

Framework: Next.js (App Router)

Styling: Tailwind CSS (Slate & Teal clinical design system)

Database: Prisma ORM

Data Visualization: Chart.js (via react-chartjs-2)

Video Telehealth: Jitsi Meet External API (WebRTC)
